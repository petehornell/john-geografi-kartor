Träna på kartbegrepp

En kort övning inför fredag 27 november. Börja med att läsa orden. Testa sedan dig själv.

1. Läs och lär

Tryck på ett begrepp för att visa förklaringen. Försök gärna säga förklaringen med egna ord.

2. Para ihop

Välj det begrepp som passar bäst till varje förklaring.

3. Använd begreppen

Välj det bästa svaret.

4. Förklara själv

Svara med egna ord. Det här avsnittet rättas inte automatiskt.

Kom ihåg: En skalstav visar hur ett avstånd på kartan motsvarar ett avstånd i verkligheten.
Du kan göra om frågorna hur många gånger du vill.
